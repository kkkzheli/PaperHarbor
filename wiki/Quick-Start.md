# 快速开始

## 1. 安装

从 Releases 下载 `PaperHarbor-1.0.0.apk`，点开安装。这是正式构建（`debuggable=false`），
包名 `io.github.kkkzheli.paperharbor`，需要 Android 8.0（API 26）及以上。

系统可能提示「未知来源应用」，那是侧载的正常提示；纸港不申请网络权限，也没有后台服务。

## 2. 新建第一本笔记

- 书架右下角 **＋** → 输入名称（可留空）→ 选纸张（横线 / 方格 / 空白）→ **创建**。
- 也可以从右上角 **导入** 菜单导入 PDF、图片，或之前导出的 `.phnote` 备份。

## 3. 写字

默认是硬笔。直接在页面上书写即可：

- 手指或手写笔都行；两指可以平移和缩放。
- 单指按住不动再拖，就是普通笔迹；画歪了按 **撤销**。
- 想要毛笔的粗细过渡，点开画笔选择框，选 **软笔**。

## 4. 换颜色和粗细

- 调色盘：点击工具栏里的圆形色块，转动色轮选色相，下面的滑杆调亮度。
- 笔尖：点击最右的粗细按钮（画笔状态下会直接打开画笔面板）。

## 5. 离开前

所有改动会即时保存到本机。标题下方的状态从「保存中…」变成「已存本机」就说明写完了。

> 卸载应用会删除所有笔记。重要的本子请用 **更多 → 备份** 导出 `.phnote`，存到自己的文件夹。
