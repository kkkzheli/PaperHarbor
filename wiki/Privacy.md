# 离线与隐私

## 没有网络权限

`AndroidManifest.xml` 里没有 `INTERNET`，也没有 `ACCESS_NETWORK_STATE`，并且用
`tools:node="remove"` 显式移除任何依赖可能带进来的这两个权限。构建完成后可以用
`aapt dump badging` 或仓库里的 `tools/verify-apk.py` 复核：实际打包的权限**只有**
`RECORD_AUDIO`。

## 数据流向

| 内容 | 位置 | 会不会离开设备 |
|---|---|---|
| 笔记、笔迹、页内文字 | 应用私有目录 | 不会 |
| 识别文本 | 同上 | 不会 |
| 闪卡与自评 | 同上 | 不会 |
| 录音 | 应用私有目录 `audio/` | 不会 |
| 导出/备份文件 | 你选择的文件夹 | 由你自己处理 |

## 麦克风

只有点击「开始录制」时才会申请麦克风权限，拒绝也不影响其他功能。录音保存在本机，
可以在录音面板里回听或删除。

## 唯一的例外

设置页里的 GitHub 链接需要你主动点击，这时系统浏览器会打开网页——这不是应用在联网，
而是浏览器在联网。应用本身没有任何联网代码路径。

## 关于第三方

文字识别使用 Tesseract4Android（Apache License 2.0）与随包提供的 `chi_sim`、`eng` 语言数据，
识别过程完全在本机完成，不调用任何在线服务。
