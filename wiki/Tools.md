# 工具箱

底部工具栏完全用图标表达，可横向滚动；从左到右依次是：画笔、荧光笔、橡皮擦、套索、图形、魔法笔、
文字、图片、漫游。最右侧的颜色与笔尖不参与滚动，始终固定，方便随时换色换粗细。

## 画笔：硬笔与软笔

**点击一次**选中画笔；**再点一次**打开画笔面板。

| 类型 | 特点 | 适用 |
|---|---|---|
| 硬笔 | 粗细稳定，按压力度轻微收锋 | 笔记正文、勾画重点 |
| 软笔 | 粗细随书写速度与压力变化，起笔收笔平滑收细 | 标题、书法感的手写 |

面板里是同一个笔尖滑杆和四个尺寸预设，上方是实时笔触预览。软笔与硬笔各自记住自己的粗细。
软笔的宽度只在一个平缓的范围内浮动，粗笔时笔身保持均匀；起收笔是渐变的圆头，
不会出现针尖、鼓包或缺口。

## 荧光笔

半透明的宽笔触，覆盖在文字上不会挡住下面的内容。再次点击荧光笔按钮会打开它的面板：
一条粗细滑杆和一条不透明度滑杆（15%–100%），上方是实时预览。默认不透明度约 38%，
调高更像马克笔，调低更适合叠在印刷文字上。

## 橡皮擦：两种模式

**点击一次**选中橡皮；**再点一次**打开橡皮面板，里面有两个模式：

- **按笔迹擦除**：碰到哪一笔就整笔删除，适合整段重写。
- **范围擦除**：只擦掉扫过的那一段，笔迹会被切开成两段，其余部分保留。

两种模式共用同一个半径滑杆，面板中间的圆圈就是实际大小。手写笔的橡皮端（如果有）会直接
进入橡皮，不会留下笔迹。

## 图形

点击图形按钮直接打开图形选择框，共十种：直线、箭头、矩形、圆、椭圆、三角形、菱形、五边形、
五角星、六边形。

选中后在页面上从一个角拖到另一个角即可。拖动过程中可以实时看到形状，松手固定。
圆与椭圆会按拖出的范围自动保持比例。

## 魔法笔

随手画个大概就好：

- 画得比较直 → 变成一条精确的直线
- 画一个圈 → 变成圆或椭圆
- 画一个方框 → 变成矩形
- 画一个三角形 → 变成规整的三角形

认不出来时会**保留你的原笔迹**，不会把字写坏。再点一次魔法笔按钮，可以在面板里指定目标：
**自由 / 直线 / 矩形 / 圆 / 椭圆 / 三角形**。「自由」按形状自动判断；选了具体图形后，
下一笔会直接按该图形还原，适合手抖或者想快速画标准图的时候。

1.1 起识别按「先看角、再看椭圆」的顺序判断：闭合处有接缝的方框不会再被当成圆，宽扁的矩形
也不会被误判成菱形；抖动的直线与三角形同样能还原。

## 文字

用 **文字** 工具点按页面空白处，会打开文字面板：

- 输入多行文字，随时修改。
- 四种字体：衬线、无衬线、等宽、手写。
- 字号滑杆（10–100）、粗体、斜体、下划线、左/中/右对齐。
- 一排颜色色位，选中的颜色会保存在页面上。

面板底部还有三个动作：

- **识别**：在本机识别当前页的印刷文字，把结果放进输入框。
- **公式**：把输入框里的 LaTeX 排版成真正的数学公式。支持 `\frac`、`\sqrt`（含 `\sqrt[3]`）、
  上下标、`\left…\right`、`\overline`、`\vec`、希腊字母、`\sum` / `\prod` / `\lim` 的上下限、
  常见函数与运算符。点一下按钮开启，再点一下取消；保存后公式按当前字体（衬线 / 无衬线 /
  等宽 / 手写）绘制，根号会盖住被开方的内容，分数会上下叠放。
- **翻译**：把当前文字交给系统分享面板，由你安装的翻译应用处理；纸港本身不联网。公式块
  交给翻译应用的是转换后的 Unicode 文本。

保存后文字块出现在页面上。用文字工具点它一下即可选中，出现「编辑 / 克隆 / 删除」气泡，拖动可以移动。
公式块再次编辑时，输入框里显示的是原来的 LaTeX 源码，方便继续修改。

## 图片

**图片** 工具会打开系统选择器，把一张图片放进当前页：默认按页面宽度的 62% 居中放置，
可直接拖动。选中时气泡里可以克隆或删除。图片保存在笔记目录的 `images/` 下，备份会一起带走。

## 漫游

**漫游** 是专门的浏览模式：

- 单指拖动移动页面。
- 双击放大到 2.5×，再双击恢复。
- 双指缩放、拖动照常可用；松手后剩下的一根手指可以继续移动页面。
- 再点一次漫游按钮退出，页面自动恢复「适配页面」。

漫游模式下不会画出笔迹，适合在密密麻麻的页面上找位置。
