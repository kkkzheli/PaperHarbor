# 数据、导出与备份

## 存在哪里

每本笔记是应用私有目录下的一个文件夹，包含 `note.json`（笔迹、文字块、图片引用与页面设置）、
可选的 `source.pdf`（导入的 PDF 原件）、`images/`（插入或导入的图片）和 `audio/`（录音）。
其他应用无法读取这个目录。

## 导出 PDF

**更多 → 导出 PDF**，或书架长按 → 导出 PDF。页面与批注会合成到一个普通 PDF，
适合发给别人查看或打印。它不是可编辑备份：导出后无法再拿回来继续修改笔迹。

## 导出单页图片

**更多 → 导出图片** 把当前页渲染成两倍尺寸的 PNG，直接存进相册的 `Pictures/PaperHarbor`，
不需要选位置也不需要存储权限（Android 10 及以上；更旧的系统会打开系统的保存面板）。
**分享图片** 则直接打开系统分享面板。

## 导出 Word

**更多 → 导出 DOCX** 把每一页渲染成页面图片并打包成 `.docx`。收件人用 Word、LibreOffice 或 WPS
就能看到完整页面与批注，不需要安装纸港；代价是页面里的文字不能再编辑。

## 分享

**更多 → 分享备份 / 分享 PDF / 分享图片**，或书架长按 → 分享备份。分享走系统面板与只读提供器，
不需要存储权限。详见 [分享与文件格式](Sharing)。

## 备份与恢复

**更多 → 备份** 生成 `.phnote` 文件，里面是笔记的完整可编辑内容：笔迹、页内文字、识别文本、
闪卡和录音。

- 恢复：书架 **导入 → 备份**，会新建一本笔记，**不会覆盖**原有内容。
- `.phnote` 就是一个 ZIP（`note.json` + `images/` + `audio/`），没有加密。里面有你的笔迹和录音，
  请当作私人文件保管。
- 恢复时会校验文件结构，损坏或越界的备份会被拒绝，而不是写坏你的存储。

## 换设备

旧设备：备份成 `.phnote` 并拷贝到新设备（或用系统分享）。新设备：导入这个 `.phnote`。

> 应用没有云备份，卸载等于删除。**卸载前请先导出备份。**
