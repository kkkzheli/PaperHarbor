# 分享与文件格式

纸港不联网，但文件可以进出：导入常见的文档，带着批注按原格式导出，或把可编辑的 `.phnote`
交给另一台装了纸港的设备。

## 分享入口

- 编辑器：**更多 → 分享备份 / 分享 PDF / 分享图片**。
- 书架：长按笔记 → **分享备份**。

分享使用系统面板，文件通过一个只读的内容提供器交给接收方，所以不需要存储权限，也不会把
应用私有目录暴露出去。临时文件放在应用缓存里，下一次分享时会被清理。

## 四种导出

| 格式 | 什么时候用 | 对方需要纸港吗 |
|---|---|---|
| `.phnote` | 换设备、长期备份、继续编辑 | 需要 |
| PDF | 打印、发给任何人、保留原 PDF 页面 | 不需要 |
| `.docx` | Word 用户查看带批注的页面 | 不需要 |
| PNG | 贴到聊天、文档或网页 | 不需要 |

只有 `.phnote` 保留可编辑的笔迹；其余三种都是「渲染后的结果」，用来给别人看。

## 导入 PDF：只读原文，上面批注

**书架 → 导入 → PDF 文档**。每一页会按原尺寸渲染成页面底图，你可以用画笔、荧光笔、套索、
文字块和图片在其上批注。原文内容不会被改写，原 PDF 文件也不会被改动。

导出时选择 **导出 PDF**，得到的是一份新的 PDF：页面尺寸与原件一致，批注已经压平在里面。
没有安装纸港的人打开它，看到的就是你批注后的样子。

## 导入 Word（.docx）：文字重排成页面

**书架 → 导入 → Word 文档**。纸港读取 `word/document.xml` 里的文字，按当前纸张尺寸重新分页，
每一页都可以像普通页面一样批注。

- 保留：段落文字、换行、制表符。
- 舍弃：字体、字号、颜色、图片、表格边框（表格会压平成带空格的文字）。
- 不支持旧版 `.doc`：请在 Word 里另存为 `.docx` 或 PDF 再导入。

导出选择 **更多 → 导出 DOCX**。生成的 `.docx` 每一页是一张页面图片（包含你的批注），
Word、LibreOffice、WPS 都能打开；它是给人看的，不能在里面继续编辑原文。

## 导入图片

**书架 → 导入 → 图片或照片**：图片会变成一本笔记的第一页，可以在上面批注。
编辑器里的 **图片** 工具是另一个功能：把一张图片放到当前页的任意位置，可拖动、克隆、删除。

## 导出单页 PNG

**更多 → 导出图片** 把当前页渲染成两倍尺寸的 PNG，直接保存到相册的 `Pictures/PaperHarbor`：
Android 10 及以上不需要选位置，也不需要存储权限，保存后会提示存放位置。系统更旧时会改用
系统的保存面板。**分享图片** 则把同一张 PNG 交给系统分享面板。
文件名来自笔记标题，中文标题同样可以分享——提供器会把文件名原样交给接收方。

## 备份与恢复

**导出/分享 `.phnote`** 会把笔记的完整可编辑内容打成一个 ZIP：`note.json`、`images/` 里的图片、
`audio/` 里的录音。恢复时新建一本笔记，不会覆盖原来的。

- 恢复前会校验结构，损坏或越界的备份会被拒绝。
- `.phnote` 不加密，里面有你的笔迹和录音，请当作私人文件保管。

## 边界

- 纸港不修改导入文档的正文，也不支持在页面里编辑 Word 的段落。
- PDF 与 `.docx` 导出会压平批注；要保留可继续编辑的笔迹，请分享 `.phnote`。
- 翻译不在纸港里完成，见 [工具箱](Tools) 的「文字块」一节。
