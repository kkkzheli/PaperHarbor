# 1.1.0 验收记录

1.1.0 在 1.0 的基础上补齐封面、纸张、文字、图片、漫游、分享与文档格式。存储格式向后兼容：
旧笔记可以直接打开；新写入的页面会多出 `texts`、`images`、`tint` 等字段，旧版本不认识它们，
因此跨版本同步 `.phnote` 前请两端一起升级。

## 自动化

| 验收 | 结果 |

| 离线 Gradle 构建（debug / release） | 通过；构建期继续校验 OCR 引擎与两个模型摘要 |

这一轮在真机上测试的始终是 **释放版**（`debuggable=false`，包名 `io.github.kkkzheli.paperharbor`）。
Android 侧不允许用 adb 安装新的测试 APK（MIUI 的 USB 安装限制），所以仪器测试这一轮没有在
真机上重跑，回归以释放版的实际操作为主。

## 真机检查（Xiaomi arm64，Android 16，1220×2712）

- **封面**：新建面板的书脊/横带/标签/素面四种样式与八种颜色可以预览，创建后书架封面按选择绘制；
  长按笔记可以在「封面」里再次修改。
- **纸张**：新建时选择横线/方格/点阵/空白/康奈尔与六种纸色；「更多 → 页面样式」逐页更换后页面
  立即重绘，预览同步更新。
- **软笔**：手绘正弦曲线，弯道平滑、没有尖角，粗细随速度变化。
- **魔法笔**：抖动的圆、方框、三角形、直线分别还原成圆、矩形、三角形、直线；宽扁矩形不再被误判
  为菱形，闭合处有接缝的方框也不再变成圆（离线用同一套算法跑过 10 组形状用例）。
- **范围擦除**：在高亮的圆上横擦一刀，只移除了被扫过的弧段，圆的其他部分保留。
- **荧光笔**：面板里的不透明度从 38% 调到 60% 后，新画的笔迹明显更实。
- **文字**：点按页面放置文字，四种字体、字号、粗体与颜色生效；保存后文字出现在页面上，选中时
  出现编辑/克隆/删除气泡。
- **图片**：从系统选择器插入截图，图片按页面 62% 宽度居中放置，可拖动；分享面板与导出均包含它。
- **漫游**：进入漫游后单指拖动页面、双击放大到 2.5×、再点一次退出并恢复适配页面。
- **分享**：`分享备份` 生成的 `ph-import.phnote` 出现在系统分享面板；`分享 PDF`、`分享图片` 走同一条
  只读提供器，不需要存储权限。
- **Word**：导入 60 段的 `.docx` 得到 2 页可批注文字；批注后导出 `.docx`，`python-docx` 能打开该文件，
  读到 2 个内嵌页面图片，页面图片里包含批注笔迹。
- **备份**：导出的 `.phnote` 内含 `note.json` 与 `images/img-1.png`，`note.json` 里的封面、纸色、
  文字块、图片引用与荧光笔 alpha 都正确写入。
- **设置**：强调色、语言（简体中文 / English / 跟随系统）、荧光笔不透明度、新笔记默认纸张与封面、
  用量统计、清空缩略图缓存均可用；底部署名显示 `纸港 v1.1.0 · kkkzheli`，与 Releases 的版本号一致。

## 未验证

- `.docx` 恢复（把导出的 `.docx` 再导入）只做了结构校验，未在 Word/LibreOffice 里人工打开。
- 真实 Word 文档的复杂排版（表格、图片、多级标题）不在导入保真范围内，只保留文字。
- 仪器测试本轮未在真机运行（安装被测 APK 被系统限制）；测试源码仍然随仓库维护。
- 平板与折叠屏：用 1220×2712 与横屏验证了自适应列数与底部工具栏的固定色块，未在真实大屏设备人工检查。

## 已知取舍

- `.docx` 导入只保留文字；导出把每页渲染成页面图片，因此收件人无需纸港也能看到批注，但文字不可再编辑。
- PDF 导出把批注压平；只有 `.phnote` 保留可继续编辑的笔迹。
- 翻译通过系统分享交给其他应用完成，纸港自身不联网。
- 图片只能移动、克隆、删除，暂不支持缩放把手；文字块支持四种字体，不含字号逐字调整。
