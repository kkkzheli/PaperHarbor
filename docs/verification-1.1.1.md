# 1.1.1 验收记录

1.1.1 是一次修复版：处理粗笔迹的笔画缺口、范围擦除的切口、粗软笔的笔形、图形/魔法笔的选中样式，
并重做 PNG 导出的保存方式。存储格式没有变化，1.1.0 的笔记与 `.phnote` 可以直接继续使用。

## 修复项与真机检查（Xiaomi arm64，Android 16，1220×2712）

- **笔迹末端的缺口**：粗笔迹的末端以前会出现一个圆形小洞。原因是笔画轮廓把圆形笔帽作为
  独立子路径叠加，子路径方向相反时被非零填充规则挖空。现在笔帽是轮廓本身的一段半圆弧，
  整条笔迹只有一个闭合轮廓。重新打开旧笔记后，原有粗笔迹的缺口立刻消失（笔迹数据没有改动）。
- **范围擦除**：在 28 px 的软笔笔迹上横向使用半径 24 的范围擦除，切口是干净的圆头，
  不会再出现凹口、针尖或“被咬掉一块”的边缘；规则图形的切段同样干净。
- **粗软笔笔形**：宽度系数改为平缓的速度/压力模型（0.45–1.32），平滑与首尾渐细都拉长到多个采样点，
  拐角处的斜接上限降到 1.25。28 px 的直线与圆弧笔身均匀，起收笔是渐变的圆头。
- **图形选择框**：选中的图形现在把**图标本身**填成强调色（反白图标），不再在整个选项周围加一圈大框；
  工具按钮与选项都关闭了系统的焦点框，弹出面板关闭后不会在按钮外留下方框。
- **魔法笔**：再次点击魔法笔会打开可选面板，提供自由、直线、矩形、圆、椭圆、三角形六种目标。
  选择后按钮高亮、弹出提示，并在下次打开时保持选中；「自由」仍按形状自动判断。
- **PNG 导出**：**更多 → 导出图片** 在 Android 10 及以上直接写入相册的 `Pictures/PaperHarbor`，
  不再经过文件选择器，也不需要存储权限。真机导出的文件为 1224×1584 RGBA PNG（139,625 字节），
  内容与页面一致；媒体库插入失败时会自动回退到系统保存面板。
- **分享中文标题**：只读提供器以前只接受 ASCII 文件名，中文标题的笔记会在接收方打开时失败。
  现在除路径分隔符和控制字符外都允许，中文标题的 PNG 可以正常打开系统分享面板。

## 追加验证

- **书架卡片**：每张卡片在标题下显示「页数 · 占用大小」和完整的保存时间，例如
  `1 page · 79.5 KB` / `22 Nov 2026, 09:28`；中文界面为 `1 页 · 79.5 KB` /
  `2026年11月22日 09:28`。大小按笔记目录递归统计（note.json、images、audio）。
- **公式排版**：`\frac{\sqrt{a+b}}{2c}+x_{i+1}=\sum_{k=0}^{n}\frac{1}{k!}` 在页面上按真实排版绘制：
  根号的横线覆盖被开方内容，分数上下叠放，`\sum` 的上下限分别排在符号的上方与下方。衬线、
  无衬线、等宽、手写四种字体都逐一切换检查过，字形与根号、分数线均正常；导出的 PNG 里公式
  与页面显示一致。
- **翻译交接**：公式块点「翻译」后会打开系统分享面板，面板预览里的文字是转换后的 Unicode
  （`(√(a+b))(2c)+x_{i+1}=∑ k=0^n 1/(k!)`）。纸港自身不联网，真正的翻译由接收应用完成。
- **文字面板布局**：英文界面下「Scan / Formula / Translate」三个按钮原本会把 Translate 挤成
  「Translat / e」两行；改为等宽紧凑按钮后三个动作保持单行，中文界面同样正常。

## 未验证

- 只验证了分享面板能够打开；没有真的把文件发进聊天应用，接收端的二次打开未逐个人工确认。
- 翻译只验证了「交给系统分享面板」这一步，设备上没有安装翻译类应用，实际译文未生成。
- 公式排版覆盖分数、根号、上下标、上下限、希腊字母与常用运算符；矩阵、多行对齐、`\begin{…}`
  环境不在支持范围内。
- Android 10 以下的系统保存面板回退没有在真实旧设备上运行。
- 仪器测试本轮仍未在真机运行（MIUI 限制安装新的测试 APK）；测试源码继续随仓库维护。
- 平板与折叠屏没有新增人工检查。

## 已知取舍

- PNG 固定按页面两倍尺寸渲染，不提供自定义分辨率。
- 分享用的临时文件放在应用缓存里，下一次分享时清理。
- 范围擦除后的碎片保存为自由笔迹（不再是参数化图形），这是为了保留“只擦掉一段”的效果。
