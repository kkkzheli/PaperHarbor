# 1.0.0 验收记录

1.0.0 是界面与工具的重做版本：新增软笔、图形与魔法笔、套索变换、深浅色主题、设置页和双语。
存储格式与 0.2.0 兼容，旧笔记可直接打开；新写入的笔迹可能带 `brush` 与 `shape` 两种新类型，
0.2.0 不认识它们，因此请在两端都升级后再同步 `.phnote`。

## 真机检查（设备所有者授权）

Xiaomi arm64，Android 16（API 36），1220×2712、480 dpi，系统深色模式。安装释放版后逐项确认：

- 书架、编辑器、深色主题与新建笔记面板；纸张预览保持纸色。
- 画笔面板：硬笔/软笔切换、透明笔触预览、粗细滑杆与预设；软笔实际书写可见粗细过渡与收锋。
- 橡皮面板：按笔迹擦除 / 范围擦除切换，半径预览与预设。
- 图形面板：十种图形，选中态高亮。
- 套索：框选后出现虚线框、四角缩放手柄与旋转手柄；拖动移动、拖角按比例放大、拖旋转手柄旋转，
  小气泡的克隆可用，全部变换后状态回到「已存本机」。
- 魔法笔：手绘矩形被还原为标准矩形，手绘直线被还原为直线。
- 调色盘：色轮、亮度滑杆、十六进制值与 8 个色位。
- 设置：浅色/深色/跟随系统切换会重建界面，压感滑杆、纸张默认值、本机用量统计正常。
- 深色与浅色两套配色均完整可用。

## 未验证

- 实体触控笔的压感手感与侧键行为（真机未接入手写笔）。
- 真实麦克风采音的音质与长时间录音。
- 系统文件选择器的导入/导出界面（自动化无法操作系统选择器）。
- 平板与折叠屏：仅用 `wm size` 模拟了 360 dp 与横屏，未在真实大屏设备上人工检查；网格列数按宽度
  自适应，滚动面板在宽屏下限制为 620 dp 并居中。

## 已知取舍

- 选中后的缩放框是旋转后内容的**轴对齐**外框，不是随内容旋转的框；缩放与旋转仍然以选区中心为准。
- 范围擦除会把笔迹切成多段，形状（矩形、圆等）无法局部擦除，碰到即整条删除。
- 魔法笔只识别直线、圆、椭圆、矩形和三角形；其余笔迹原样保留。
- 深色主题只改变界面，纸张始终是纸色，避免深色墨迹在深色纸面上消失。
