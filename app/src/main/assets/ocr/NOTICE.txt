PaperHarbor — offline printed-text OCR

The APK includes an unmodified Android OCR engine and two unmodified language
models. Pages and results are never sent to a service by this feature. There is
no first-run download. OfflineOcr recognizes upright, printed Simplified Chinese
and English; it is not a handwriting recognizer or an orientation detector.

Build and runtime
  Apply 'ocr.gradle' in the app module. It adds the local AAR and verifies the
  three SHA-256 pins before a build; it does not fetch or run anything from
  those URLs. No additional repository, Android permission, API key or service
  is required. The app calls OfflineOcr.recognize(Context, Bitmap) off the UI
  thread. Pass an upright software bitmap and bound any source render/decode
  before calling: OCR cannot undo the caller's allocation. The JNI input is
  capped at 5,000,000 pixels and 3,200 pixels on either edge. Each call creates
  and releases one native engine; processing is serialized and the caller keeps
  ownership of its bitmap. Only the verified models are copied on demand to
  noBackupFilesDir/offline-ocr/tessdata/; this feature writes no page images or
  recognition results to disk. Errors are reported rather than faking text or
  falling back to a network provider.
