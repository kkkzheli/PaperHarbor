# 纸港 · PaperHarbor

**简体中文** · [English](README.md)

一款不需要账号、网络或密钥的 Android 笔记本。书写、输入、识别、录音和格式转换全部在本机完成，
应用不声明 `INTERNET` 或 `ACCESS_NETWORK_STATE`。

纸港 1.1 由 **kkkzheli** 独立实现，与 Goodnotes 无从属或授权关系，没有使用该产品的代码、素材，
也不读取或继承任何订阅。

## 功能

- **书架**：每本笔记的封面有自选的样式与颜色；卡片下方显示页数、占用大小与完整的保存时间
  （年/月/日 时:分）；可按标题、页内文字、导入文档文字和识别文本搜索；
  可按最近修改、标题或页数排序。
- **封面**：书脊、横带、标签、素面四种样式，八种颜色，新建时可预览，之后也能在长按菜单里修改。
- **纸张**：横线、方格、点阵、空白、康奈尔五种样式与六种纸色；新建时选定，之后可在
  「更多 → 页面样式」里逐页调整。
- **画笔**：硬笔（压感收锋）、软笔（粗细随速度、压力与弯折变化，粗笔时笔身保持均匀，收笔不再出现
  尖角或缺口）、半透明荧光笔。再次点击当前画笔按钮会打开选择框、笔尖滑杆与实时预览；荧光笔的面板里
  可以单独调节不透明度。
- **橡皮**：可按笔迹整条擦除，也可只擦掉扫过的范围；范围擦除对圆、矩形等规则图形与粗笔迹都有效，
  切口是圆头，不会留下被咬掉一块的边缘。
- **图形与魔法笔**：一个选择框提供直线、箭头、矩形、圆、椭圆、三角形、菱形、五边形、五角星和
  六边形；魔法笔把大致的手绘变成直线、圆、椭圆、矩形、菱形或三角形，认不出来时保留原笔迹。
  再点一次魔法笔按钮，可以在「自由 / 直线 / 矩形 / 圆 / 椭圆 / 三角形」里指定要还原的图形。
- **文字块**：用文字工具点按页面即可放置可编辑文字，支持四种字体、字号、颜色、粗体、斜体、下划线
  与左/中/右对齐。「公式」把输入框里的 LaTeX 排成真正的数学式——分数上下叠放、根号的横线盖住
  被开方内容、`\sum` / `\prod` / `\lim` 的上下限排在符号上下方——并跟随所选字体。「识别」在本机
  读取整页印刷文字，「翻译」把文字交给已安装的其他应用。
- **图片**：把照片或截图插入页面，可拖动、克隆或删除。
- **漫游**：专门的浏览模式，单指移动页面、双击放大、双指缩放，看细节时不用切换工具。
- **套索**：选中后拖动移动，拖四角按比例缩放，用上方的手柄旋转；气泡里可以克隆或删除。
- **调色盘**：色相/饱和度色轮加独立亮度滑杆，8 个色位可长按保存当前颜色，另有最近使用颜色。
- **页面**：缩略图网格、书签、样式与纸色、复制、前后移动、删除，以及跳转到下一个书签页。
- **文字与识别**：页内文字可被书架搜索；横排印刷的简体中文与英文由 Tesseract4Android 在本机识别。
- **闪卡与录音**：双面闪卡自评复习；录音保存为本机 AAC，可回听或删除。
- **导入**：PDF、图片、`.docx` 与 `.phnote`。PDF 或 Word 会变成一本可批注的笔记，原文内容只读，
  你在上面添加笔迹、文字块与图片。
- **导出与分享**：PDF、单页 PNG（Android 10 及以上直接存进 `Pictures/PaperHarbor`，不用选位置、
  不要存储权限）、可编辑的 `.phnote`，或把批注一起渲染成页面图片的 `.docx`。分享面板通过只读的
  文件提供器把任意一种交给其他应用。
- **设置**：浅色/深色/跟随系统、六种强调色、语言（跟随系统/简体中文/English）、只用手写笔绘制、
  压感灵敏度、荧光笔不透明度、橡皮默认范围擦除、新笔记的纸张与封面默认值、本机用量、
  清空缩略图缓存，以及作者、仓库与版本发布链接。
- **多语言**：简体中文与英文，跟随系统或在设置里指定。

## 格式对照

| 格式 | 导入 | 批注 | 导出 |
|---|---|---|---|
| `.phnote` | 可以，恢复成一本新笔记 | 可以，笔迹仍可编辑 | 可以，这是可编辑的母本 |
| PDF | 可以，逐页渲染 | 可以 | 可以，保留原页面尺寸的扁平 PDF |
| `.docx` | 可以，文字重新排版成页面 | 可以 | 可以，批注渲染进页面图片的 `.docx` |
| PNG / 图片 | 可以，成为一本笔记的一页 | 可以 | 可以，当前页导出为 PNG |
| `.doc`（旧格式） | 不支持，请先另存为 `.docx` 或 PDF | — | — |

纸港不会修改导入文档的正文或排版，也不会改动原文件：批注添加在页面上，导出时生成新文件。

## 边界

- **翻译不是内置功能**：「翻译」会打开系统分享面板，由你安装的其他应用完成翻译。纸港本身不联网。
- `.docx` 导入保留可读的文字，但不保留 Word 的排版：表格被压平，图片与样式被舍弃，分页按纸张
  重新计算。
- PDF 与 `.docx` 导出会把批注压平，只有 `.phnote` 能重新打开并继续编辑笔迹。
- **不导入 `.goodnotes` 私有文档**。旧资料请先导出 PDF，再在其上批注。
- 不提供账号、云同步、多人协作、内容商店、远程 AI、Office 转换、笔迹同步录音回放或语音转写。
- **卸载前请先导出备份。** 没有云端副本，`.phnote` 也不加密，里面有你的笔迹和录音，请自行妥善保管。

## 安装

在 Releases 下载 `PaperHarbor-1.1.1.apk` 侧载安装。这是正式构建（`debuggable=false`），包名
`io.github.kkkzheli.paperharbor`，要求 Android 8.0（API 26）及以上。

签名密钥与密码不会上传，APK 里只有公开证书。想用自己的密钥重新构建，请见
[docs/building.md](docs/building.md) 与 Wiki 的「构建与签名」。

## 构建

需要 JDK 17 以上、Android SDK Platform 34 与 Build Tools 34，并设置 `ANDROID_HOME` 或在
`local.properties` 写入 `sdk.dir`。

```powershell
.\gradlew.bat --offline assembleDebug assembleRelease
```

```powershell
python -I .\tools\verify-apk.py .\app\build\outputs\apk\release\app-release.apk --build-tools "$env:ANDROID_HOME\build-tools\34.0.0"
```

`verify-apk.py` 会核对实际打包的权限是否恰好只有 `RECORD_AUDIO`、验证签名并输出 SHA-256。
仪器测试在专用设备或模拟器上用 `connectedDebugAndroidTest` 运行；`tools/offline-smoke.py`
在飞行模式下驱动真实界面，`tools/layout-check.py` 检查竖屏、横屏与 360 dp。本次构建的验收记录见
[docs/verification-1.1.1.md](docs/verification-1.1.1.md)。
